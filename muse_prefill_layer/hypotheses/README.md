# muse_prefill_layer hypotheses

One markdown file per hypothesis. `/hypothesize` writes into `queue/` and never commits;
`/churnsubs` is the only writer after that: it moves a file to `running/` when it claims it
(worktree + branch `hyp/muse_prefill_layer/<slug>`), runs it exactly once, and moves it to
`done/<outcome>/` with `<slug>.patch` and `<slug>.result.json` beside it. Outcomes: gain,
neutral, regression, failed, rejected. `BEST.json` is the best proven result on master's lineage;
`INDEX.md` and `FINDINGS.md` are regenerated by `churn.py index`. Never hand-edit those three.
