Speeding up one layer of a language model: 49 versions in 12 days

A language model writes one token (a word fragment) at a time, and every token passes through the same stack of layers on a GPU. This page follows one of those layers through the 2026 Open Kernel Challenge, a contest to rewrite its GPU code so it runs faster. A judge timed every entry on an NVIDIA H200 GPU against SGLang, a widely used open-source engine for running these models.

The code that does the work is a set of kernels: functions that run on the GPU, launched one after another. Each block in the picture is one kernel.
