## Question (pre-registered)

With a device-side gate, does the T=128 hybrid win on every draw? The gate runs the hybrid only when the hot set is large enough, and plain E5 otherwise.

**Rule:**
- If the gated arm is <= 0.97 of master in every round on every draw, and exact, it becomes a moe check candidate.
- Otherwise the residual loss is recorded.

## Gate design (no host branch, graph static)

**The gate itself:**
- `_hm_align_kernel` gets a `GATE` constexpr. With 0 the code is unchanged.
- Every program already counts all local experts, so each one computes the hot-route total itself: the routes of the experts with more than 16 routes.
- When that total is below GATE, the kernel clears the hot set, so every expert is cold:
  - The hot class is empty: n_padded is 0 and every block is -1.
  - The forked `wg_gather` and the two `wh_gemm` launches still run, but every CTA exits.
  - The E5 cold half then does every route, which is the same work as master's plain E5.

**Tail:**
- The gated route ends with master's plain-E combine (`ea_combine`, post_norm_w) instead of `fused_post_expert_norm_weighted_sum`.
- Because of that, the gate-off output equals master's output **bit for bit**.

**Threshold:**
- X = 60 hot routes, pre-registered from t128h's single-hot draws: 28 and 46 routes lost or tied, while 75, 78 and 128 won.

## Verdict (pre-registered rule)

**No candidate; T=128 stays plain E5.**

**The gate cannot help:**
- **The plain case costs x1.042-1.045 on average** (round range 1.009-1.071), about 11 us out of about 260 us.
- That cost covers the align launch, the forked empty `wg_gather` and `wh_gemm` launches (persistent CTAs that occupy SMs before exiting), and the event join.
- gon <= goff on every draw with at least 17 hot routes. The only exception is hot routes 0, where they tie at 1.05.
- So the best threshold is "no gate". At X = 60 the gate turned draws the hybrid wins (44-50 routes: gon 0.94-0.98) into x1.04 losses.

**Even a free gate cannot pass the rule:**
- A gated-off draw is plain by construction, so it sits at about 1.00 and can never be <= 0.97.

**Residual loss without a gate (arm gon):**
- Draws with 17-28 hot routes: x1.00-1.025.
- A draw with no hot expert: x1.05.
- Among the 12 judge-shaped p10 / p50 / p90 draws, only s2 p10 (28 routes) loses, at x1.022 / 1.025.

**Side finding (not in the rule):**
- Swapping the hybrid's tail to master's `ea_combine` (gon vs w16f) is worth about 2.3% at T=128 on every draw: mean 0.934 vs 0.956, and the same in both replicates.
- This agrees with the glue lane's "ea_combine at the hm tail" (hopper/glue-1029).
- With that swap, 11 of 12 judge-shaped draws win by 5-17%. That is still not every round, so it is no candidate under the rule.

**Transfer caveat:** these are forked H100 HBM ratios. CLAIMS has the T=128 hybrid sign flipping between node and judge (H100:229-231), so nothing here transfers as numbers.

**Reopen if:** the plain case's fixed cost drops below about 1%, or the rule changes to a mean or expected-headline criterion. In either case, gon's mean of 0.934 is the number to triage.
